## Studying a C64 original

How mega-dust reverse-engineered Metal Dust:

* Boot the original in VICE, dump memory at known moments with the remote monitor, and match the
  dumps against the disk files. Watch for RLE or packed files; mega-dust's level files were
  zero-run RLE.
* Find the render routine from the VIC registers (`io d000`). Search the code for `STA` into
  screen RAM, then disassemble (65816: `mega-dust`'s scratch disassembler idea; VICE `d` also works).
* Record gameplay by sampling the game's sprite multiplexer tables and scroll registers every
  half second. A bot plays the game: see `mega-dust/tools/vice/bot.py` and
  `mega-dust/tools/record_waves.py`.
* Write the formats down in `docs/FORMATS.md` as you find them.
